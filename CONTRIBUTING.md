# Contribuer

Merci de votre intérêt pour la formation.

- **Une erreur, un exemple, un retour d'animation :** ouvrez une [issue](https://github.com/MaximeRumpler/Marketing_Mix_9P/issues/new/choose) avec le formulaire *Remarque sur la formation*. Pour une erreur factuelle, joignez une source.
- **Une modification des diapositives :** le PowerPoint est un fichier binaire qu'on ne peut pas fusionner proprement. Décrivez la modification dans une issue ; l'auteur l'intègre et publie une nouvelle version.
- **Une traduction ou une adaptation :** publiez-la sous CC BY-SA 4.0 en citant la source (voir [NOTICE](NOTICE)), puis signalez-la dans une issue pour qu'elle soit listée dans le README.

Les échanges se font en français. En contribuant, vous acceptez que votre contribution soit diffusée sous [CC BY-SA 4.0](LICENSE).
