# Exercice 2 : canevas 9P

*Durée : 30 à 45 minutes. Copiez ce canevas dans un document, ou imprimez la [fiche A4](../formation/Fiche_9P_A4.pdf).*

**Mon offre, mon projet ou mon idée :** …

**Qui doit dire oui :** …

| P | Question | Ma réponse aujourd'hui | Ce qui manque ou coince |
|:--|:--|:--|:--|
| 1. Produit | Quel besoin mon offre résout-elle vraiment ? | | |
| 2. Prix | Quel prix le client accepte-t-il, et que dit-il de ma valeur ? | | |
| 3. Place | Où et comment le client accède-t-il à mon offre ? | | |
| 4. Promotion | Comment faire connaître et désirer mon offre ? | | |
| 5. Personnes | Qui délivre l'offre, et avec quelle qualité de contact ? | | |
| 6. Processus | Quel parcours le client traverse-t-il pour en profiter ? | | |
| 7. Preuves physiques | Quels signaux tangibles rassurent sur la qualité ? | | |
| 8. Purple Cow | Qu'est-ce qui rend mon offre digne d'être racontée ? | | |
| 9. Partenariat | Avec qui créer plus de valeur qu'en restant seul ? | | |

## Les interactions

- Le P que je change en premier : …
- Le P que je dois vérifier juste après, et pourquoi : …

## Pour vous relire

- Quelle question vous a mis le plus mal à l'aise ?
- Laquelle avez-vous sautée ?
- Si vous ne pouviez traiter qu'un seul P ce trimestre, lequel déplacerait le plus les autres ?
